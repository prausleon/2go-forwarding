# 2GO Forwarding Website Wireframes

HTML/Tailwind wireframe system based on the two provided 2GO Forwarding / 2GO corporate presentation PDFs.

## Prototype

Open `index.html` directly in a browser. The wireframes use Tailwind CSS via CDN for rapid prototyping and intentionally avoid production dependencies.

## Architecture

- `index.html` — Homepage
- `services.html` — Services hub
- `sea-freight.html` — Sea Freight / LCL / FCL
- `air-freight.html` — Air Freight
- `land-transport.html` — Land Transportation
- `specialized-solutions.html` — Pharma, Cold Chain, Motorcycle, Events, Mall Logistics
- `industries.html` — Industry solutions
- `network.html` — Network / ports / assets
- `contact.html` — Quote / inquiry journey
- `sitemap.md` — Proposed information architecture and URLs
- `seo-geo-llmo.md` — Search, Generative Engine and LLM visibility strategy
- `design.md` — Wireframe design system and implementation notes

## Source discipline

Content is grounded in the supplied PDFs. Claims that need verification before production launch are marked in the documentation rather than invented.

## Production direction

The wireframes prioritize clear service taxonomy, crawlable HTML, semantic headings, internal linking, entity/context signals, FAQ content, structured data opportunities, performance, accessibility, and conversion paths for B2B logistics inquiries.
